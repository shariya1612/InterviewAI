 InterviewAI
 AI-Powered Mock Interview & Feedback Platform

Overview

InterviewAI is an AI-powered web application designed to help students and job seekers prepare for technical and HR interviews. The platform generates interview questions based on the selected role and evaluates user responses using AI, providing personalized feedback, improvement suggestions, and progress tracking.
